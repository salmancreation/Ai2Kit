Overview

AI builders make beautiful sites in minutes, but the result is React code or a single HTML file — not something you can edit in WordPress. Ai2Kit reads the page the way a browser renders it and rebuilds it with Elementor's own containers and widgets, so every heading, button, image and section is editable like a page you built yourself.

◆

Real Elementor, not an embed

Flexbox and Grid containers, headings, text, buttons, images, icons, icon lists, videos and accordions.

◎

Local and private

The conversion runs in your browser and saves on your server. Ai2Kit Free makes no requests to Ai2Kit's servers and collects no data.

▣

Your design system

Colors and fonts become Elementor Global Colors & Fonts, and widgets link to them.

↺

Review, then undo

Every section gets a match score before import. One click undoes an import completely.

Install

  1. Install ElementorPlugins → Add New → search “Elementor” → Install → Activate.
  2. Install Ai2KitPlugins → Add New → search “Ai2Kit”, or Upload Plugin and choose ai2kit.zip. Activate it.
  3. Open Ai2Kit → ConvertThe first screen checks your site and tells you if anything needs attention.

Quick start

Ai2Kit works in four steps, shown at the top of the screen.

  1. UploadDrop an .html file, a ZIP of an HTML template, or a ZIP of a built Lovable/Bolt/v0 site — or choose Paste HTML instead. Ai2Kit shows what it detected, for example Lovable (Vite + React) · 96%; click the badge to see why.
  2. CheckPreflight checks (Elementor version, Flexbox Container, PHP limits). Blocking problems show in red, often with a one-click Enable or Fix. Choose what to create (a draft page or an Elementor template), the title, and the Elementor format (Auto, v4 Atomic or v3 classic).
  3. ReviewThe page renders and converts in your browser at desktop, tablet and mobile widths. Every section gets a score, and you can switch any section between Native and HTML. The Tokens tab shows your colors and fonts.
  4. ImportClick Import to WordPress. Images go to the Media Library, tokens to your Elementor kit, and the page is created as a draft. Then click Edit with Elementor.
TipOn the Done screen, Compare with the source shows the original and the Elementor page side by side, with swipe and overlay views, at every width.

Preparing your site

Ai2Kit converts what a browser can render. For single HTML pages that's the file itself; for React/Vite projects it's the built output, not the source code.

Lovable, Bolt and other Vite + React projects

  1. Get the project locally (Lovable: GitHub sync or Download; Bolt: Download).
  2. Build it with a relative base so asset paths work from any folder:
npm install
npm run build -- --base=./
  1. ZIP the dist folder and upload it.

Uploaded the source ZIP by mistake (with package.json and src/)? Ai2Kit tells you and shows these steps. Built without --base=./? Ai2Kit fixes most absolute /assets/… paths automatically and tells you how many.

v0 and Next.js

Use a static export (output: 'export' in next.config.js, then next build) and ZIP the out folder.

Claude, ChatGPT, Gemini Canvas

Copy the full page (from <!doctype html> to </html>) and use Paste HTML instead, or save it as index.html and upload it. Pages that load Tailwind from its CDN work as they are.

HTML templates

ZIP the template folder with its HTML, CSS, JS and images. If the ZIP has several HTML files, index.html is converted.

Limits

  • Upload size: 50 MB by default (a filter can raise it — see Developers).
  • ZIPs are checked for unsafe paths and symbolic links, at most 5,000 files and 200 MB unpacked; PHP and other server-side files are left out.
  • Free converts the page at / of a multi-page app. Pro converts every page.

Reviewing a conversion

Sections and scores

Each section (Header, Hero, Features grid, FAQ, Footer …) has a thumbnail, the widgets it became, and a score:

ScoreMeaning
90%+A close native match
70–89%Native, with differences worth a look
below 70%Ai2Kit suggests keeping it as HTML

Hover a score for its breakdown: structure (how much became real widgets), styles (how many visual properties became Elementor controls) and HTML kept. The overall match at the top is weighted by section size.

Native or HTML

  • Native — Elementor containers and widgets. Fully editable; small differences from the source are possible.
  • HTML — the section exactly as in the source, inside one Elementor HTML widget. Pixel-exact, but you edit it as HTML.

You can mix both on one page.

Design tokens

The Tokens tab shows the colors and fonts Ai2Kit found — read directly from shadcn/ui theme variables (Lovable, v0), or the most-used colors and fonts on other sites. Rename them if you like. Merge adds them next to your existing globals; Replace overwrites the four system globals for the whole site (backed up, and restored by Undo).

What gets converted

Ai2Kit reads the page at 1440, 1024 and 390 px wide and writes responsive values only where tablet or mobile differ from desktop.

In the sourceIn Elementor
Sections, rows, columns, gridsFlexbox or Grid containers (padding, gaps, alignment, widths, boxed width)
h1–h6, large display textHeading
Paragraphs, rich text, listsText Editor
Links and buttons that look like buttonsButton (with its icon)
<img>Image (imported to the Media Library)
SVG iconsIcon — the site's own SVG, cleaned and uploaded
Lists with icons; unbulleted link lists (footer columns)Icon List
YouTube, Vimeo, <video>Video
<hr>, empty spacersDivider, Spacer
Accordions and FAQs (Radix/shadcn, <details>)Nested Accordion, with every answer captured
Forms, tables, iframes, canvasHTML widget (kept as is)

Hover effects

:hover styles become Elementor's hover controls: background and text colors, borders, shadows, lift/scale and the transition duration. In v4 they become the element's hover state.

Backgrounds

Background colors, gradients and images map to Elementor's Background controls. A hero with a separate image layer and a dark overlay becomes the section's own background image with a Background Overlay.

v3 or v4

With Atomic elements (v4), headings, paragraphs, buttons, images, icons and containers become Elementor 4 atomic elements; widgets without an atomic version stay classic on the same page.

Styles without an Elementor control

Gradient text, rotations, blur and similar effects are kept as a small stylesheet that applies only to the converted page. It is validated on your server before it's saved.

Not converted

  • App features: logins, dashboards, databases — anything that needs a backend.
  • canvas/WebGL and complex absolutely positioned layouts (kept as HTML).
  • In Free: forms stay HTML; tabs and carousels stay as static content; only the page at / of a multi-page app.

Import, History & Undo

What an import does

  1. Re-checks everything the browser sent — only known Elementor widgets and settings are accepted; text is sanitized and URLs are checked.
  2. Imports images into the Media Library. Identical files are reused, not duplicated; SVGs are cleaned.
  3. Adds design tokens to your Elementor kit, after backing up the current kit.
  4. Creates the page (a draft) or template through Elementor's own document API, so revisions and CSS work normally.

The Done screen lists what was created and Things to check: blocks kept as HTML, forms to connect, scoped CSS, icons or images that couldn't be imported.

History

Ai2Kit → History lists every conversion with its date, source, pages, score and status. View report shows the section scores again; Re-run starts a new conversion.

Undo

Undo (from History or the Done screen) moves the created page to the trash, deletes the images the import added (images already in your library are left alone) and restores your Global Colors & Fonts. If the page was edited after import, Ai2Kit warns you first.

AI agents (MCP) New in 0.4

Ai2Kit registers agent tools with WordPress. An AI agent connected over MCP (Claude Desktop, Claude Code, Cursor, VS Code) can prepare conversions, read reports and undo imports — using Ai2Kit's tested converter instead of improvising Elementor code.

ToolWhat it does
ai2kit/preflightChecks the site can import
ai2kit/create-jobPrepares a conversion from HTML the agent has, or a .zip/.html in the Media Library; returns a review link
ai2kit/list-jobsRecent conversions, with edit links and scores
ai2kit/get-jobOne conversion's report
ai2kit/undo-importUndoes an import (asks first if the page was edited)

Converting needs one click from you: Ai2Kit renders the page in a real browser, so the agent gives you a link — open it, click Start conversion, review and import.

Requirements and setup

WordPress 6.9+ and the MCP Adapter (Elementor 4.3+ includes it). For a site on your computer, add this to your MCP client's configuration:

{
  "mcpServers": {
    "my-wordpress": {
      "command": "wp",
      "args": [ "--path=/path/to/wordpress", "mcp-adapter", "serve",
                "--server=mcp-adapter-default-server", "--user=admin" ]
    }
  }
}

For a site on a server, use @automattic/mcp-wordpress-remote with an Application Password (Users → Profile). For safety, agents can't pass a web address to download, only administrators can use the tools, and imports are always drafts.

Privacy & security

  • Uploads are stored in a private folder in your uploads directory, protected from listing and PHP execution, and deleted after import or 24 hours.
  • The conversion runs in your browser; the result is saved on your server. Ai2Kit Free makes no requests to Ai2Kit's servers and collects no usage data.
  • While converting, your browser loads what the uploaded page references (for example a Tailwind or Google Fonts CDN) — as when you open the page yourself. With Import remote images on, your server downloads the page's external images.
  • The browser's output is never trusted: the server re-validates every element and setting, sanitizes text and URLs, and cleans SVGs with an allowlist. Every REST endpoint checks permissions and a nonce.

Troubleshooting

My React/Vite site converts to a blank page
You uploaded the project source, or the build can't find its files. Upload the built dist folder as a ZIP, built with npm run build -- --base=./.
Images are missing
The build uses absolute /assets/… paths. Ai2Kit fixes most automatically (the Check step says how many); building with --base=./ fixes the rest. For images on other hosts, check Settings → Import remote images.
Imported pages render blank
Elementor's Flexbox Container is off. Turn it on in Elementor → Settings → Features, or click Enable in the Check step.
A section looks different
Switch it to HTML in Review to keep it pixel-exact, or keep it Native and adjust it in Elementor. A section's details show why it scored lower.
Fonts don't match
Ai2Kit adds fonts to your Global Fonts and Elementor loads Google Fonts automatically. Fonts a site hosts itself must be added in Elementor → Custom Fonts (Elementor Pro) or by your theme.
“Your account can't run scripts”
Pages that run JavaScript can only be converted by users allowed to add unfiltered HTML — administrators, or network super admins on multisite.
The upload fails or is rejected
Remove large videos or unused files (50 MB limit by default), check the server upload limit shown in the Check step, and upload only the built site (at most 5,000 files, 200 MB unpacked).
The import times out
Imports with many images can hit the PHP time limit; 60 seconds or more and 256 MB of memory are recommended.

Filters

// Raise the upload limit (default 50 MB).
add_filter( 'ai2kit_max_upload_bytes', function () {
	return 100 * MB_IN_BYTES;
} );

Extension API

Ai2Kit Free contains no locked features; add-ons extend it through documented hooks. Check the AI2KIT_EXTENSION_API constant (currently 1) before using them.

  • Engine (window.ai2kit.engine, script handle ai2kit-engine): registerExtension() with capture, recognition and emit hooks.
  • Admin app (@wordpress/hooks): ai2kit.check.pages, ai2kit.convert.morePages, ai2kit.import.
  • PHP: ai2kit_enqueue_admin_scripts, ai2kit_admin_script_dependencies, ai2kit_admin_config, ai2kit_allowed_widgets, ai2kit_nested_widgets, ai2kit_import_result, ai2kit_undo_import.

Translations

All strings use the ai2kit text domain; language packs from translate.wordpress.org install automatically. Bangla is complete.

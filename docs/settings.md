# Settings

**Ai2Kit → Settings**

| Setting | What it does |
|---|---|
| **Theme** | Light, Dark, or follow your system. Only affects Ai2Kit's screens. |
| **Create** | Default output: a new draft page or an Elementor template. You can change it per conversion. |
| **Elementor format** | **Auto** uses Atomic elements (v4) when Elementor's Atomic editor is on, otherwise classic widgets (v3). Or force one. |
| **Global Colors & Fonts** | **Merge** adds tokens as custom globals. **Replace** overwrites the four system globals for the whole site (always backed up). |
| **Import remote images into the Media Library** | On (default): images the page loads from other hosts are downloaded into your Media Library. Off: they keep their original addresses. |
| **Keep uploaded files for re-runs** | Off (default): uploads are deleted after import, or after 24 hours. On: kept so you can re-run a conversion. |
